A collection of mini-projects, exercises, and experiments while learning Rust.

This repository follows [The Rust Programming Language](https://doc.rust-lang.org/book/) and explores Rust fundamentals through hands-on practice.

## Projects

| Project | Description | Concepts |
|---|---|---|
| `hello-cargo` | First Cargo project | Cargo basics |
| `guessing-game` | A simple number guessing game | Variables, input, loops, matching |
| `temperature-converter` | Convert between Celsius, Fahrenheit, and Kelvin | Functions, parsing, control flow |
| `fibonacci` | Calculate the nth Fibonacci number using different algorithms | Recursion, iteration, dynamic programming, complexity analysis |

## Goals

- Build a solid understanding of Rust fundamentals.
- Practice problem-solving through small projects.
- Explore different algorithms and compare their complexity.
- Learn ownership, borrowing, and memory safety through practice.

## Running a Project

Each project is an independent Cargo package.

```bash
cd <project-name>
cargo run
```
